# Проверка готового сайта

Дата: 5 сентября 2026 года. Среда: Chromium 153.0.8010.12 под управлением Playwright 1.63.0, axe-core через @axe-core/playwright 4.13.0, html-validate 10.17.0.

## Результат

`report.json` — машинный отчёт выполненного сценария: **82 проверки пройдены, 0 неуспешных**.

- HTML прошёл `html-validate:recommended` без ошибок и предупреждений.
- Проверены 15 размеров окна: 360×800, 375×812, 390×844, 428×926, 560×800, 600×900, 760×900, 768×1024, 820×1180, 980×900, 981×900, 1024×768, 1280×720, 1440×1000, 1920×1080.
- Проверялся не только scrollWidth: границы реального текста заголовков, абзацев, кнопок, меню и подписей полей также не выходят за экран.
- Пять проверок axe с правилами WCAG 2 A/AA, 2.1 AA и 2.2 AA: начальный десктоп, открытое эссе, готовая заявка, открытое мобильное меню, экран 360 px. Автоматически обнаруженных нарушений — 0. Неопределимые автоматикой пункты отражены в `manualReviewItems` отчёта.
- Все разделы, семь принципов манифеста, восемь FAQ, локальные якоря и ссылки SVG существуют. Повторяющихся ID нет.
- Мобильное меню: открытие/закрытие, Escape, цикл Tab, переход к разделу, возврат фокуса и разблокировка прокрутки.
- Вкладки: мышь, стрелки, Home/End; корректные aria-selected, tabindex и видимость панелей.
- FAQ: открытие, закрытие предыдущего ответа, клавиша Enter.
- Цитаты: смена в обе стороны и циклическое возвращение.
- Медиа: три полных материала, открытие/закрытие, Escape, возврат фокуса, переход из диалога к заявке.
- Форма: пять ошибок пустого ввода, ошибочный контакт, выбор направления, счётчик, кодекс, корректная подготовка заявки.
- Копирование с честным резервным сценарием, скачивание полного UTF-8-файла с расширением `.txt`, точность текста в ссылке Телеграма.
- Редактирование ответов, защита от HTML-инъекции через текстовые значения, отсутствие cookie/localStorage/sessionStorage и сетевой передачи формы.
- Обычная анимация частиц и IntersectionObserver отдельно проверены без reduced motion; режим уменьшенного движения также проверен.
- `file://` с отключённой сетью: все изображения, локальные шрифты, вкладки и подготовка заявки работают.
- Без JavaScript основные тексты читаются, нативный FAQ работает, форма честно отключена.
- Ошибок выполнения JavaScript и HTTP-ошибок ресурсов не обнаружено. Фоновых запросов к сторонним сервисам и POST-запросов нет.

## Проверка дистрибутива

После основной проверки создана однофайловая версия. `verify-release.cjs` выполняет ещё семь проверок самого файла: встраивание изображений, CSS и скриптов; загрузка локальных шрифтов; навигация без интернета; навигация и реальная подготовка заявки кликом и клавишей Enter в `sandbox="allow-scripts"`; отсутствие ошибок JavaScript. Результат находится в `report.json → distribution`.

Для повторения сначала выполните `python3 tools/prepare_release.py` из корня сайта, затем `npm run test:release` из каталога `verification`. После этого повторная упаковка включит обновлённый отчёт в ZIP.

## Воспроизведение

Самому сайту Node.js не нужен. Следующие зависимости предназначены только для проверки.

1. Запустите сервер из корня сайта:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

2. В другом терминале:

```bash
cd verification
npm install
npx playwright install --with-deps chromium
npm test
```

Если сервер работает по другому адресу, задайте переменную окружения `SITE_URL`. Проверка перезаписывает `report.json` и пять скриншотов. Данные тестовой заявки явно помечены как технический тест, ничего не отправляется внешнему адресату.

## Границы проверки

Автоматическая проверка доступности не заменяет аудит с реальными ассистивными технологиями. Safari, Firefox, физические мобильные устройства, ответы команды в Телеграме и работа чужих площадок здесь не тестировались. Официальные адреса намеренно не выдуманы. Проверена именно полностью реализованная статическая страница и её честный локальный сценарий заявки.
